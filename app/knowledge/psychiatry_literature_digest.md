# Выжимка литературы по психиатрии

Этот файл подготовлен как единая внутренняя клиническая база для Сушкевич Бота.

Пока он содержит только заглушку. Когда будет готов большой файл с выжимкой литературы,
его содержимое можно перенести сюда или указать путь к нему через переменную
`CLINICAL_KNOWLEDGE_PATH`.
